# xet CLI Tool Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `xet` developer CLI binary in `xet_pkg` for uploading files, downloading by hash, analyzing dedup/compression stats, and querying reconstruction metadata against a Xet CAS endpoint.

**Architecture:** A binary at `xet_pkg/src/bin/xet/` split into focused modules — `main.rs` for CLI parsing, `session.rs` for building sessions/clients from CLI args, and one file per command (`upload.rs`, `download.rs`, `stats.rs`, `query.rs`).  All upload/download goes through `XetSession` + `XetSessionBuilder`.  Stats use `FileUploadSession::dry_run` with a `TranslatorConfig` (local shard cache, no network).  Query uses `RemoteClient` or `LocalClient` directly via the `Client` trait.

**Tech Stack:** Rust, `clap` (derive), `tokio`, `serde_json`, `xet_pkg` (`XetSession`, `UploadCommit`, `DownloadGroup`), `xet_data` (`FileUploadSession`, `TranslatorConfig`, `SessionContext`), `xet_client` (`RemoteClient`, `LocalClient`, `AuthConfig`, `NoOpTokenRefresher`)

  ```rust
  mod download;
  mod query;
  mod session;

  use anyhow::Result;
  use clap::{Parser, Subcommand};

  use download::DownloadArgs;
  use query::QueryArgs;
  use stats::StatsArgs;
  use upload::UploadArgs;

  const DEFAULT_HF_ENDPOINT: &str = "https://huggingface.co";

  /// Xet CAS developer tool for uploading, downloading, and inspecting files.
  #[derive(Parser)]
  #[command(name = "xet", version)]
  pub struct Cli {
      /// CAS endpoint URL or local path.
      /// - https://...          remote server
      /// - /absolute/path       local disk store (normalized to local://)
      /// - local:///path        local disk store
      /// Defaults to HF_ENDPOINT env var, then https://huggingface.co.
      #[arg(long, global = true)]
      pub endpoint: Option<String>,

      /// Auth token for remote endpoints.
      /// Defaults to HF_TOKEN env var. Not required for local endpoints.
      #[arg(long, global = true)]
      pub token: Option<String>,

      /// Override a xet_config value: -c group.name=value. May be repeated.
      #[arg(short = 'c', long = "config", global = true, value_name = "KEY=VALUE")]
      pub config_overrides: Vec<String>,

      #[command(subcommand)]
      pub command: Commands,
  }

  #[derive(Subcommand)]
  pub enum Commands {
      /// Upload one or more files to the CAS endpoint.
      Upload(UploadArgs),
      /// Download a file by its xet hash.
      Download(DownloadArgs),
      /// Dry-run dedup and compression analysis (no upload).
      Stats(StatsArgs),
      /// Show reconstruction metadata for a file hash.
      Query(QueryArgs),
  }

  impl Cli {
      /// Resolve the endpoint to a canonical form:
      /// - absolute paths are prefixed with "local://"
      /// - local:// URLs are returned as-is
      /// - https:// URLs are returned as-is
      /// - None falls back to HF_ENDPOINT env var or the HF default
      pub fn resolved_endpoint(&self) -> String {
          let raw = self
              .endpoint
              .clone()
              .unwrap_or_else(|| std::env::var("HF_ENDPOINT").unwrap_or_else(|_| DEFAULT_HF_ENDPOINT.to_owned()));
          normalize_endpoint(&raw)
      }

      /// Resolve the token: --token flag, then HF_TOKEN env var, then None.
      pub fn resolved_token(&self) -> Option<String> {
          self.token
              .clone()
              .or_else(|| std::env::var("HF_TOKEN").ok())
              .filter(|t| !t.is_empty())
      }
  }

  /// Normalizes an endpoint string: absolute filesystem paths get a `local://` prefix.
  pub fn normalize_endpoint(raw: &str) -> String {
      if raw.contains("://") {
          raw.to_owned()
      } else if raw.starts_with('/') {
          format!("local://{raw}")
      } else {
          raw.to_owned()
      }
  }

  fn main() -> Result<()> {
      let cli = Cli::parse();

      // Apply -c config overrides before building the runtime.
      // The config is both installed globally (via XetRuntime) for xet_config()
      // callers (stats, query) AND forwarded explicitly to XetSessionBuilder
      // (upload, download) so that overrides take effect in both paths.
      let mut config = xet_runtime::config::XetConfig::new();
      for kv in &cli.config_overrides {
          let (key, val) = kv.split_once('=').ok_or_else(|| anyhow::anyhow!("--config must be KEY=VALUE, got: {kv}"))?;
          config = config.with_config(key, val)?;
      }

      // Install the config globally and spin up the thread pool.
      let runtime = xet_runtime::core::XetRuntime::new_with_config(config.clone())?;

      runtime.external_run_async_task(async move {
          match cli.command {
              Commands::Upload(args) => upload::run(&cli, config, args).await,
              Commands::Download(args) => download::run(&cli, config, args).await,
              Commands::Stats(args) => stats::run(&cli, args).await,
              Commands::Query(args) => query::run(&cli, args).await,
          }
      })?
  }
  ```

  ```rust
  use std::sync::Arc;

  use anyhow::{Context, Result};
  use xet::XetSession;
  use xet::xet_session::XetSessionBuilder;
  use xet_client::cas_client::auth::AuthConfig;
  use xet_client::cas_client::remote_client::RemoteClient;
  use xet_client::cas_client::simulation::LocalClient;
  use xet_client::cas_client::Client;
  use xet_data::processing::configurations::TranslatorConfig;
  use xet_runtime::config::XetConfig;
  use xet_runtime::core::xet_cache_root;   // correct path — NOT utils::file_paths

  const LOCAL_SCHEME: &str = "local://";

  /// Build a XetSession for upload/download commands.
  /// Takes an explicit XetConfig so that -c overrides are forwarded to the session.
  pub async fn build_xet_session(endpoint: &str, token: Option<String>, config: XetConfig) -> Result<XetSession> {
      let mut builder = XetSessionBuilder::new_with_config(config).with_endpoint(endpoint.to_owned());
      if let Some(tok) = token {
          builder = builder.with_token_info(tok, u64::MAX);
      }
      builder.build_async().await.context("Failed to build XetSession")
  }

  /// Build a TranslatorConfig for the stats (dry-run) command.
  /// Stats always runs locally — it never sends data to the network —
  /// so we use the local path from a local:// endpoint, or a stable
  /// shard-cache directory for remote endpoints.
  pub fn build_translator_config(endpoint: &str) -> Result<Arc<TranslatorConfig>> {
      let config = if endpoint.starts_with(LOCAL_SCHEME) {
          let path = endpoint.strip_prefix(LOCAL_SCHEME).unwrap();
          TranslatorConfig::local_config(path)?
      } else {
          // Dry-run: no network calls needed. Use a stable local shard cache dir.
          // Note: xet_cache_root() is in xet_runtime::core, not utils::file_paths.
          let cache_dir = xet_cache_root().join("xet-cli-stats");
          std::fs::create_dir_all(&cache_dir)?;
          TranslatorConfig::local_config(&cache_dir)?
      };
      Ok(Arc::new(config))
  }

  /// Build a CAS client for the query command.
  pub async fn build_cas_client(endpoint: &str, token: Option<String>) -> Result<Arc<dyn Client>> {
      if endpoint.starts_with(LOCAL_SCHEME) {
          let path = endpoint.strip_prefix(LOCAL_SCHEME).unwrap();
          let client = LocalClient::new(path).await.context("Failed to create LocalClient")?;
          Ok(client as Arc<dyn Client>)
      } else {
          let auth = token.map(|t| AuthConfig::maybe_new(Some(t), None, None)).flatten();
          Ok(RemoteClient::new(endpoint, &auth, "", false, None) as Arc<dyn Client>)
      }
  }
  ```

  ```rust
  use std::path::PathBuf;

  use anyhow::Result;
  use clap::Args;
  use serde_json;
  use xet::XetSession;
  use xet::xet_session::upload_commit::FileMetadata;
  use xet_data::processing::Sha256Policy;

  use super::Cli;

  #[derive(Args)]
  pub struct UploadArgs {
      /// Files to upload.
      pub files: Vec<PathBuf>,

      /// Compute SHA256 hash during upload (default: true).
      #[arg(long = "sha256", default_value_t = true, action = clap::ArgAction::Set)]
      pub sha256: bool,

      /// Write JSON results to this file instead of stdout.
      #[arg(long)]
      pub output: Option<PathBuf>,
  }

  pub async fn run(cli: &Cli, config: xet_runtime::config::XetConfig, args: UploadArgs) -> Result<()> {
      let session = super::session::build_xet_session(&cli.resolved_endpoint(), cli.resolved_token(), config).await?;
      let results = run_upload(session, args).await?;
      for meta in &results {
          println!(
              "{}  hash={}  size={}  sha256={}",
              meta.tracking_name.as_deref().unwrap_or("<unknown>"),
              meta.hash,
              meta.file_size,
              meta.sha256.as_deref().unwrap_or("-")
          );
      }
      Ok(())
  }

  /// Core upload logic, separated for testability.
  pub async fn run_upload(session: XetSession, args: UploadArgs) -> Result<Vec<FileMetadata>> {
      let sha256 = if args.sha256 { Sha256Policy::Compute } else { Sha256Policy::Skip };

      let commit = session.new_upload_commit().await?;
      let mut handles = vec![];
      for path in &args.files {
          let handle = commit.upload_from_path(path.clone(), sha256.clone()).await?;
          handles.push((path.clone(), handle));
      }

      let results_map = commit.commit().await?;
      let mut output = vec![];
      let mut had_error = false;

      for (path, handle) in handles {
          // `UploadTaskHandle` exposes `task_id: Ulid` as a public field (via Deref to TaskHandle).
      let id = handle.task_id;
          match results_map.get(&id) {
              Some(result) => match result.as_ref() {
                  Ok(meta) => output.push(meta.clone()),
                  Err(e) => {
                      eprintln!("ERROR: {}: {e}", path.display());
                      had_error = true;
                  },
              },
              None => {
                  eprintln!("ERROR: {}: no result returned", path.display());
                  had_error = true;
              },
          }
      }

      if had_error {
          anyhow::bail!("one or more files failed to upload");
      }
      Ok(output)
  }
  ```

  > **Note on `UploadTaskHandle`:** `upload_from_path` returns an `UploadTaskHandle` which derefs to `TaskHandle`.  The tracking ID is a public field: `handle.task_id` (type `Ulid`), defined in `xet_pkg/src/xet_session/progress.rs` line 36.  There is no `tracking_id()` method.

  ```rust
  use std::path::PathBuf;
  use std::sync::Arc;

  use anyhow::Result;
  use clap::Args;
  use ulid::Ulid;
  use walkdir::WalkDir;
  use xet_data::deduplication::DeduplicationMetrics;
  use xet_data::processing::configurations::TranslatorConfig;
  use xet_data::processing::file_upload_session::FileUploadSession;
  use xet_data::processing::Sha256Policy;

  use super::Cli;

  #[derive(Args)]
  pub struct StatsArgs {
      /// Files or directories to analyze.
      pub files: Vec<PathBuf>,

      /// Process directories recursively.
      #[arg(short, long)]
      pub recursive: bool,

      /// Write JSON results to this file instead of stdout.
      #[arg(long)]
      pub output: Option<PathBuf>,
  }

  pub async fn run(cli: &Cli, args: StatsArgs) -> Result<()> {
      let config = super::session::build_translator_config(&cli.resolved_endpoint())?;
      let metrics = run_stats(config, args).await?;

      println!("total_bytes={}  new_bytes={}  deduped_bytes={}  uploaded_bytes={}",
          metrics.total_bytes, metrics.new_bytes, metrics.deduped_bytes, metrics.total_bytes_uploaded);

      if metrics.total_bytes > 0 {
          let dedup_pct = 100.0 * metrics.deduped_bytes as f64 / metrics.total_bytes as f64;
          let compression_pct = if metrics.new_bytes > 0 {
              100.0 * (1.0 - metrics.total_bytes_uploaded as f64 / metrics.new_bytes as f64)
          } else {
              0.0
          };
          println!("dedup_ratio={:.1}%  compression_ratio={:.1}%", dedup_pct, compression_pct);
      }

      Ok(())
  }

  pub async fn run_stats(config: Arc<TranslatorConfig>, args: StatsArgs) -> Result<DeduplicationMetrics> {
      let session = FileUploadSession::dry_run(config, None).await?;

      let files: Vec<PathBuf> = collect_files(&args.files, args.recursive);

      let file_entries: Vec<(PathBuf, Sha256Policy, Ulid)> = files
          .into_iter()
          .map(|p| (p, Sha256Policy::Skip, Ulid::new()))
          .collect();

      session.upload_files(file_entries).await?;

      // finalize takes `self: Arc<Self>` — call it directly; Rust dispatches correctly.
      let metrics = session.finalize().await?;

      Ok(metrics)
  }

  fn collect_files(inputs: &[PathBuf], recursive: bool) -> Vec<PathBuf> {
      if !recursive {
          return inputs.to_vec();
      }
      inputs
          .iter()
          .flat_map(|p| {
              WalkDir::new(p)
                  .follow_links(false)
                  .into_iter()
                  .flatten()
                  .filter(|e| e.file_type().is_file())
                  .filter_map(|e| Some(e.path().to_path_buf()))
          })
          .collect()
  }
  ```

  ```rust
  use std::path::PathBuf;

  use anyhow::{Context, Result};
  use clap::Args;
  use xet::XetSession;
  use xet_data::processing::XetFileInfo;

  use super::Cli;

  #[derive(Args)]
  pub struct DownloadArgs {
      /// Hex-encoded MerkleHash of the file to download.
      pub hash: String,

      /// File size in bytes (required to construct XetFileInfo).
      pub size: u64,

      /// Destination path.
      pub output: PathBuf,
  }

  pub async fn run(cli: &Cli, config: xet_runtime::config::XetConfig, args: DownloadArgs) -> Result<()> {
      let session = super::session::build_xet_session(&cli.resolved_endpoint(), cli.resolved_token(), config).await?;
      let bytes = run_download(session, args).await?;
      // run_download prints the confirmation line; return bytes for testing.
      let _ = bytes;
      Ok(())
  }

  /// Core download logic, separated for testability. Returns bytes written.
  pub async fn run_download(session: XetSession, args: DownloadArgs) -> Result<u64> {
      if let Some(parent) = args.output.parent() {
          std::fs::create_dir_all(parent)?;
      }

      let file_info = XetFileInfo {
          hash: args.hash.clone(),
          file_size: args.size,
          sha256: None,
      };

      let group = session.new_download_group().await?;
      let _handle = group.download_file_to_path(file_info, args.output.clone())?;
      group.finish().await?;

      let bytes = std::fs::metadata(&args.output)
          .context("output file not found after download")?
          .len();

      eprintln!("Downloaded {} → {} ({} bytes)", args.hash, args.output.display(), bytes);

      Ok(bytes)
  }
  ```

  ```rust
  use std::sync::Arc;

  use anyhow::Result;
  use clap::Args;
  use xet_client::cas_client::Client;
  use xet_client::cas_types::{FileRange, QueryReconstructionResponseV2};
  use xet_core_structures::merklehash::MerkleHash;

  use super::Cli;

  #[derive(Args)]
  pub struct QueryArgs {
      /// Hex-encoded MerkleHash of the file.
      pub hash: String,

      /// Optional byte range "start-end" (inclusive), e.g. "0-1048575".
      /// `FileRange` has no FromStr impl so we accept a raw string and parse manually.
      pub range: Option<String>,
  }

  pub async fn run(cli: &Cli, args: QueryArgs) -> Result<()> {
      let client = super::session::build_cas_client(&cli.resolved_endpoint(), cli.resolved_token()).await?;
      let response = run_query(client, args).await?;
      match response {
          Some(r) => {
              println!("terms: {}", r.terms.len());
              println!("xorbs: {}", r.xorbs.len());
              let total_bytes: u64 = r.terms.iter().map(|t| t.unpacked_length as u64).sum();
              println!("total_uncompressed_bytes: {}", total_bytes);
              for (i, term) in r.terms.iter().enumerate() {
                  // Field is `hash` (HexMerkleHash), NOT `xorb_hash`.
                  println!("  term[{}]: xorb={} unpacked_len={}", i, term.hash, term.unpacked_length);
              }
          },
          None => println!("No reconstruction info found for that hash."),
      }
      Ok(())
  }

  /// Parse "start-end" string into FileRange, if provided.
  fn parse_range(s: &str) -> Result<FileRange> {
      let (start, end) = s.split_once('-')
          .ok_or_else(|| anyhow::anyhow!("range must be 'start-end', got: {s}"))?;
      Ok(start.trim().parse::<u64>()? .. end.trim().parse::<u64>()?)
  }

  pub async fn run_query(
      client: Arc<dyn Client>,
      args: QueryArgs,
  ) -> Result<Option<QueryReconstructionResponseV2>> {
      let hash = MerkleHash::from_hex(&args.hash)?;
      let range: Option<FileRange> = args.range.as_deref().map(parse_range).transpose()?;
      client
          .get_reconstruction(&hash, range)
          .await
          .map_err(anyhow::Error::from)
  }
  ```

  > **Note on `XorbReconstructionTerm`:** The struct has fields `hash: HexMerkleHash` (not `xorb_hash`) and `unpacked_length: u32`, verified at `xet_client/src/cas_types/mod.rs:181–185`.

  > **Note on `FileRange`:** `FileRange` has no `FromStr` impl — clap cannot parse it directly. Declare the field as `Option<String>` and use the `parse_range` helper above.  `FileRange` is a type alias for a `Range<u64, _>` — check the exact type at `xet_client/src/cas_types/mod.rs` and adjust the return type of `parse_range` if needed (may be `std::ops::Range<u64>`).

## Common Pitfalls

- **`UploadTaskHandle` tracking ID:** The ID is `handle.task_id` (a public `Ulid` field via `Deref` to `TaskHandle`).  There is no `tracking_id()` method.  Defined at `xet_pkg/src/xet_session/progress.rs:36`.
- **`FileUploadSession::finalize`:** Call `session.finalize().await?` directly — `finalize` takes `self: Arc<Self>` and Rust dispatches through `Arc` automatically.  Do not use `Arc::try_unwrap`.
- **`walkdir` dependency:** Already added to `xet_pkg/Cargo.toml` in Task 1.  If you see a missing crate error, re-check Step 1.1.
- **`xet_cache_root` import path:** Use `xet_runtime::core::xet_cache_root`, NOT `xet_runtime::utils::file_paths::xet_cache_root` (that path does not exist).
- **`xet_core_structures` dependency:** Needed in `query.rs` for `MerkleHash::from_hex`.  Already in `xet_pkg` dependencies as `xet-core-structures`.
- **`FileRange` type:** Has no `FromStr` impl — clap cannot parse it directly.  The `QueryArgs.range` field must be `Option<String>`; use the `parse_range` helper to convert.  `FileRange` is a `Range<u64, _>` type alias in `xet_client::cas_types`.
- **`XorbReconstructionTerm` fields:** The xorb hash field is `term.hash` (type `HexMerkleHash`), NOT `term.xorb_hash`.  Defined at `xet_client/src/cas_types/mod.rs:181`.
